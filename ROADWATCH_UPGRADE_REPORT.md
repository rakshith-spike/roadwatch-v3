## APIs Added

- `POST /api/complaints/analyze-image`
  - Runs YOLO road-defect analysis for an uploaded image URL.
- `GET /api/complaints/priority-queue`
  - Returns government/superadmin AI priority queue sorted by priority and support count.
- `POST /api/complaints/{complaint_id}/support`
  - Supports an existing complaint instead of creating a duplicate.
- `POST /api/complaints/{complaint_id}/repair-validation`
  - Compares before/after AI analysis and stores repair validation.
- `POST /api/complaints/{complaint_id}/citizen-verification`
  - Lets the citizen close or reopen a completed complaint.
- `GET /api/analytics/map-intelligence`
  - Returns clusters, heatmap cells, and hotspot regions for map rendering.

## Database Changes

- `complaints` collection now supports:
  - `support_count`, `supported_by`
  - `severity_score`, `priority_score`, `traffic_importance`
  - `estimated_cost`, `cost_range`, `cost_reasoning`, `estimated_days`
  - YOLO `bounding_boxes`, `annotated_image`, `model`, `model_status`
  - `before_work_photos`, `progress_photos`, `completion_photos`, `progress_percentage`, `work_notes`
  - `repair_validation`, `citizen_verification`
  - statuses `validation_pending` and `closed`
- `projects.work_logs` now supports before/progress/completion photo metadata and progress percentage.
- New complaint indexes:
  - `priority_score` descending
  - `support_count` descending
- Existing geospatial index on `location.coordinates` is preserved and used for nearby duplicate detection.

## New Features

- Pretrained YOLOv8 integration using `YOLO_MODEL_PATH`, defaulting to `yolov8n.pt`.
- Custom model plug-in path via `YOLO_MODEL_PATH` without adding a training pipeline.
- Backend fallback image analysis if YOLO package/weights are unavailable.
- Citizen complaint flow now supports image capture/upload, GPS capture, YOLO preview, duplicate support, severity score, cost estimate, repair estimate, and priority score.
- Duplicate complaints near the same geospatial area support the existing complaint instead of creating a new record.
- Government dashboard now includes AI priority queue, cost/time estimates, duplicate support analytics, and hotspot signals.
- Contractor dashboard now surfaces photo evidence counts, progress tracking, success rate, and average completion time.
- Super Admin dashboard now includes contractor ranking, duplicate/fraud signals, budget/resolution metrics, and problematic areas.
- Map view now renders complaint clusters and heatmap-style density circles, with citizens scoped to nearby issues.
- Lifecycle notifications added for created, verified, assigned, in progress/completed, verification requested, citizen accepted, and reopened events.
